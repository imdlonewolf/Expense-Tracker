Expense-Tracker
An intuitive, lightweight, and efficient personal finance management application designed to help users monitor daily expenses, organize spending categories, and maintain control over their financial health.

🚀 Features
Transaction Management: Seamlessly add, edit, and delete income and expense entries.

Smart Categorization & Aggregation: Organize your spending into distinct categories with category-wise expense aggregation for better financial clarity.

Secure Authentication: Robust, secure JWT-based authentication to protect user data and sessions.

Financial Overviews: View clear summaries and breakdowns of your transaction history.

🛠️ Tech Stack
Backend: .NET 8, ASP.NET Core Web API, Entity Framework Core

Frontend: React

Version Control: Git

📦 Getting Started
Prerequisites
.NET 8 SDK

Node.js and npm (for the React frontend)

Git

Installation
Clone the repository:

Bash
git clone https://github.com/your-username/Expense-Tracker.git
Navigate to the project directory:

Bash
cd Expense-Tracker
Set up the Backend:

Bash
cd backend
dotnet restore
dotnet run
Set up the Frontend:

Bash
cd frontend
npm install
npm start
💡 Usage
Launch the backend API and start the React development server.

Register or log in using secure JWT authentication.

Access the dashboard to log daily expenses, view category-wise spending distributions, and stay aligned with your financial goals.
